# Intelligent Enemy: Updated

Make existing enemies behave more intelligently without adding enemy types or changing their attributes. The original enemy-mod compatibility settings remain available.

This fork updates the original mod for Factorio 2.1.24 and retains its existing prototype and setting names. Replace the original with this fork; both cannot be enabled together. Existing-save loading and two 1,200-tick headless consistency runs completed with this fork enabled.

Original mod by plexpt: [Mod Portal](https://mods.factorio.com/mod/intelligent-enemy). Fork source: [GitHub](https://github.com/FactorioMods/intelligent-enemy-updated). Original credits and bundled license remain applicable.
